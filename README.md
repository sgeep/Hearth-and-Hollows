Hearthdelve is a small top-down action roguelite/tavern management game I'm building mostly through vibe coding with Claude (Opus 5.5).

I've had the idea for a while, primarily inspired by Dave the Diver and Delicious in Dungeon: head into a dungeon, fight monsters, bring their parts back as ingredients, then cook and serve them in your tavern.

I've tinkered with Unity before, but never made it much further than basic prototypes. This project is partly about making something I'd enjoy playing, and partly about learning what it actually takes to design, build, test, and eventually deliver a complete game.

I'm leaning on a few Unity Asset Store tools I've picked up along the way, including **TopDown Engine**, **Feel / Nice Vibrations**, and **Super Text Mesh**. Most of the game's art comes from the **Minifantasy** collection by Krishna Palacio.

Currently in development using **Unity 6.6**.
